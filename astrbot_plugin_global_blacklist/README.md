# 全局触发屏蔽

名单里的人在任何群聊、任何私聊都不会触发机器人：消息在进入模型调用之前就被拦下，不读、不回、不消耗模型。消息本身照常接收，只是不回应。

数据文件：`data/plugin_data/astrbot_plugin_global_blacklist/blacklist.json`（可直接手改，改完自动热加载）。

## 指令（不用艾特，直接发）

| 指令 | 作用 |
| --- | --- |
| `/黑名单` | 查看名单，带剩余时间 |
| `/黑名单 123456 原因` | 永久屏蔽 |
| `/黑名单 123456 2h 原因` | 限时屏蔽，到点自动恢复 |
| `/黑名单 -123456` | 移除 |

时长写法：`30m`、`2h`、`3d`、`45分钟`、`7天`、`1秒` 都可以。

## 权限

只有一级博士（YOUR_QQ_ID）和配置里 `allow_qq_list` 的成员能操作，其他人在群里怎么说都不会生效。

## 配置项

- `enable`：总开关
- `enable_in_private`：私聊是否也拦
- `tip_message`：被拦时回一句什么，留空就是纯静默
- `allow_qq_list`：额外可操作名单的 QQ

## 限时原理

条目里存 `expires_at` 时间戳，判定时发现过期就当场清掉，不依赖定时任务，重启也不影响。
